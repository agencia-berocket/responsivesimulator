# Simulador Responsivo & Comparador de Telas

Simulador de resoluções de telas mobile e desktop com suporte a arquivos `.index`, pastas locais completas, URLs reais da web e exportação em JPG e PNG.

**Desenvolvido por b.rocket - berocket@berocket.com.br**

## Executar Localmente

**Pré-requisitos:** Node.js (v18+)

1. Instalar dependências:
   `npm install`

2. Executar a aplicação:
   `npm run dev`
